2. 实验原理严格实现
Phong 光照模型（必做）
I=Iambient​+Idiffuse​+Ispecular​

环境光：Iambient​=Ka​×Clight​×Cobject​
漫反射：Idiffuse​=Kd​×max(0,N⋅L)×Clight​×Cobject​
镜面高光：Ispecular​=Ks​×max(0,R⋅V)n×Clight​
对应代码：R = normalize(reflect(-L, N)) + N.dot(H) 计算



Blinn-Phong 模型（选做 1）

核心改进：用半程向量 H 替代反射向量 R
公式：Ispecular​=Ks​×max(0,N⋅H)n×Clight​
半程向量：H=normalize(L+V)
对应代码：H = normalize(L + V) + N.dot(H) 计算



硬阴影（选做 2）

原理：从着色点向光源发射阴影射线，若射线在到达光源前击中其他物体，说明该点处于阴影中
自遮挡处理：射线起点加 1e-4 偏移，避免阴影痤疮
对应代码：is_in_shadow 函数 + 阴影因子 shadow_factor 控制光照亮度

实验报告要点
1. 实验原理总结

Phong 模型通过反射向量 R 计算高光，公式为 max(0,R⋅V)n，优点是实现简单，缺点是大角度高光易截断，边缘不自然。
Blinn-Phong 模型引入半程向量 H，公式为 max(0,N⋅H)n，通过 L+V 计算 H，避免了高光截断，高光更柔和自然，计算效率与 Phong 相当，是图形学中更常用的光照模型。
硬阴影通过阴影射线检测实现，核心是 “从着色点到光源的射线是否被遮挡”，通过深度测试保证阴影正确性，通过偏移量解决自遮挡问题。

2. 实验难点与解决

难点 1：Taichi 语法限制（函数内不支持非静态 if 中 return）→ 重构 intersect_plane，统一初始化变量后 return
难点 2：阴影痤疮（自遮挡）→ 给阴影射线起点加 1e-4 偏移，完美解决
难点 3：变量大小写错误（B/b）→ 严格统一变量命名，避免语法错误
难点 4：UI 滑块加粗 + 保留原顺序 → 通过 gui.text("") 增加垂直间距，不改动滑块逻辑与顺序
