# Lab5: 光线追踪基础实现 + 选做（玻璃材质 & 抗锯齿）

## 一、实验目标
- 理解光线投射与光线追踪的区别  
- 实现硬阴影、镜面反射、迭代式光线弹射  
- 选做：玻璃材质（折射 & 全反射）+ 抗锯齿（MSAA）

## 二、场景描述
- **左侧球体**：基础版为红色漫反射球；选做版改为淡蓝色玻璃球（折射率可调）  
- **右侧球体**：银色镜面球（完美反射）  
- **地面**：y = -1.0 的无限大平面，棋盘格纹理（黑白相间），漫反射材质  

## 三、基础功能（必做）
- [x] 主光线生成与场景求交（球体 + 平面）  
- [x] 棋盘格纹理（基于 (x, z) 坐标奇偶性）  
- [x] 硬阴影：向光源发射暗影射线，检测遮挡（带偏移防自交）  
- [x] 镜面反射：递归/迭代实现，能量衰减（反射率 0.8）  
- [x] 漫反射光照：环境光 + 漫反射，阴影内仅环境光  
- [x] 交互 GUI：光源位置 (X/Y/Z)、最大弹射次数 (1~5)  

## 四、选做功能（Bonus）
### 4.1 玻璃材质与折射 (+15%)
- 左侧球体改为玻璃材质（淡蓝色）  
- 实现斯涅耳定律的折射计算  
- 自动处理内外表面切换（入射空气→玻璃 与 玻璃→空气）  
- 全内反射检测，全反射时自动转为镜面反射  
- 折射率可调范围 1.1～2.5（GUI 滑块），实时观察扭曲程度变化  
- 透射能量衰减系数 0.95  

### 4.2 抗锯齿 MSAA (+10%)
- 每个像素采用 4 次随机亚像素采样（射线抖动）  
- 最终颜色取平均值，消除几何边缘锯齿  
- GUI 提供复选框，可实时开关对比效果

七、技术要点记录
阴影痤疮修复：阴影射线和反射射线的起点沿法线方向偏移 1e-4

迭代光线追踪：用 for 循环代替递归，符合 GPU 编程习惯

玻璃折射实现：

函数 refract() 返回 (折射方向, 是否全反射)

避免在 @ti.func 的 if 内直接 return（需先声明变量再赋值）

抗锯齿：每个像素内多次采样，使用 ti.random() 产生抖动

八、常见问题
运行报错 NameError：检查变量是否在所有分支中均被初始化（Taichi 作用域严格）

全反射无效果：确保光源位置与视角满足入射角大于临界角

抗锯齿性能：4 倍采样会降低帧率，可改为 2 或动态开关
