# 布料模拟 - 质弹簧系统 (Mass-Spring Cloth Simulation)

## 项目概述
本项目基于 **Taichi** 实现了一个三维布料模拟程序，采用 **质点-弹簧模型**，支持多种弹簧类型和球体碰撞响应。提供了三种数值积分方法（显式欧拉、半隐式欧拉、隐式欧拉）用于不同稳定性需求的模拟。

这是图形学课程作业的选做部分，完成了以下扩展：
- ✅ **完善弹簧模型**：在结构弹簧基础上增加剪切弹簧和弯曲弹簧。
- ✅ **空间碰撞**：在场景中放置球体，并实现质点与球体的碰撞检测与响应。

---

## 功能特性

### 1. 完整弹簧模型
| 弹簧类型 | 描述 | 作用 |
|---------|------|------|
| **结构弹簧** | 连接相邻水平/垂直质点 | 保持网格基本形状 |
| **剪切弹簧** | 连接对角相邻质点 | 抵抗剪切变形 |
| **弯曲弹簧** | 连接间隔一个质点的水平/垂直点 | 抵抗弯曲/折叠 |

添加剪切和弯曲弹簧后，布料表现出更真实的抗拉、抗弯特性。

### 2. 球体碰撞
- 场景中央放置一个橙色球体（可自定义位置和半径）。
- 每个时间步检测所有质点与球体的距离，对穿透的质点进行：
  - **位置修正**（推回球面）。
  - **速度响应**（根据恢复系数反弹）。
- 有效防止布料穿过球体。

### 3. 三种积分方法
| 方法 | 稳定性 | 说明 |
|------|--------|------|
| **显式欧拉** | 极差（极易发散） | 用于对比演示 |
| **半隐式欧拉** | 较好（默认推荐） | 平衡速度与稳定性 |
| **隐式欧拉（定点迭代）** | 好（略阻尼） | 更稳定但计算量稍大 |

所有物理更新均合并为单个 GPU kernel，高效利用并行计算。

## 操作说明

### 界面按钮
| 按钮 | 功能 |
|------|------|
| **Explicit Euler** | 切换到显式欧拉（极易爆炸） |
| **Semi-Implicit Euler** | 切换到半隐式欧拉（默认，推荐） |
| **Implicit Euler** | 切换到隐式欧拉（使用3次定点迭代） |
| **Pause / Resume** | 暂停/恢复模拟 |
| **Reset Cloth** | 重置布料到初始状态 |

### 视角控制
- **鼠标右键拖拽**：旋转视角
- **鼠标滚轮**：缩放
- 其他操作遵循 Taichi GGUI 的默认相机控制

## 验证选做内容
运行程序后，可通过以下现象确认选做功能已实现：

### 1. 剪切弹簧与弯曲弹簧
- 观察布料形态：比仅有结构弹簧时更“硬挺”，剪切和弯曲形变更小。
- **对比测试**：可在 `init_springs()` 函数中临时注释掉剪切弹簧和弯曲弹簧的初始化代码，重启程序，会看到布料非常柔软、容易产生对角线拉伸和尖锐折痕；恢复代码后，布料明显更方正、抗弯。

### 2. 球体碰撞
- 布料下落时会接触橙色球体，**不会穿透**，而是被球面阻挡并沿着表面滑落。
- 可用鼠标旋转视角，从侧面观察布料质点均保持在球面外部。
- 碰撞后质点速度方向被修正，具有轻微反弹（`restitution = 0.3`）。

## 参数说明（可在代码中调整）
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `N` | 20 | 布料网格分辨率（N×N） |
| `mass` | 1.0 | 质点质量 |
| `k_s` | 10000.0 | 弹簧劲度系数（越大布料越硬） |
| `k_d` | 1.0 | 阻尼系数（越大摆动衰减越快） |
| `dt` | 5e-4 | 时间步长 |
| `restitution` | 0.3 | 球体碰撞恢复系数（0=无反弹，1=完全弹性） |
| `sphere_center` | (0.0, 0.3, 0.0) | 球体中心位置 |
| `sphere_radius` | 0.25 | 球体半径 |

## 注意事项
- 显式欧拉方法仅用于演示，可能立刻发散，属于正常现象。
- 若帧率过低，可减少每帧子步数（主循环中 `for _ in range(40)` 的 40）或降低 `N`。
- 球体粒子渲染点数为 600，并非真正球体网格，仅供视觉参考。
- 当前未实现布料自碰撞，仅做演示。
