## 五、实验原理与实现说明
1.  **软光栅化（Soft Rasterization）**
    传统硬光栅化的阶跃边界会导致梯度消失，本实验使用PyTorch3D的`SoftSilhouetteShader`，通过计算像素到三角形的距离，结合Sigmoid函数实现平滑过渡，为顶点提供有效梯度。
2.  **多视角剪影优化**
    采用20个环绕视角渲染目标剪影，通过均方误差（MSE）损失，驱动球体顶点向奶牛形状变形，提升优化的鲁棒性。
3.  **网格正则化**
    为防止网格畸形，总损失加入三项正则化约束：
    - `mesh_laplacian_smoothing`：约束网格表面平滑，避免尖锐突起
    - `mesh_edge_loss`：惩罚过长/过短边，保持三角形均匀分布
    - `mesh_normal_consistency`：约束相邻面法线方向一致，避免表面扭曲
    总损失公式：
    $$L_{total} = L_{silhouette} + 1.0 \times L_{lap} + 0.1 \times L_{edge} + 0.01 \times L_{normal}$$

## 六、实验结果
- 经过300轮迭代，初始球体模型成功优化为奶牛形状，剪影误差降至`0.0141`，与目标剪影高度匹配。
- `mesh_epoch/`文件夹中保存了每20轮迭代的中间模型，完整记录了从球体到奶牛的变形过程，可通过MeshLab查看不同阶段的网格变化。
- 正则化项有效避免了网格出现尖刺、交叉等畸形问题，保证了优化后模型的拓扑合理性。
